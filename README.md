# Java Login Form

## Project Description
A simple Java AWT login form that checks the username, password, and user role.

## Features
- Validates empty username and password fields.
- Checks whether the username exists.
- Verifies the password and selected role.
- Disables the Login button after three incorrect password attempts.
- Displays a welcome page after successful login.
- Includes a Cancel button.
